Hold a key. Say it. It’s typed.

Flow is free, open-source dictation for Windows. Hold Ctrl Win, talk, let go, and your words land at the cursor in whatever app you’re in. It runs on your own PC, so what you say stays there.

Free and MIT licensed. No account. Windows 11.

Press and hold to dictate, or hold Ctrl on your keyboard. The demo is scripted: this page can’t hear you.

That took about a second.
Here it is, slowed down.

  1. Key down

    The microphone opens and the model starts loading while you take a breath. The pill appears once audio is flowing, so seeing it means speak now.

  2. You talk

    Audio is held in memory. It is never written to disk.

  3. Key up

    Silence at both ends and long pauses are cut. If you said nothing, nothing is typed.

  4. Transcribe

    Parakeet turns the audio into punctuated, capitalised text on your processor. No graphics card needed.

  5. Clean up

    Fillers and repeats go. Your dictionary fixes names. Saying “new line” makes one.

  6. Insert

    The text is pasted at your cursor, then your clipboard is put back the way it was.

Audio goes from the microphone to the model to your cursor, and never touches the network.

  • No account, no telemetry and no analytics.
  • Audio is held in memory and never written to disk.
  • History is off until you switch it on, and stays on your PC.
  • API keys are encrypted by Windows and never written to the config file.
  • The keyboard hook checks for your hotkeys and nothing else. It never logs what you type.
  • The pill shows a cloud on every dictation that leaves your machine.

You choose the model. Flow adds no markup.

Five local models are free and work offline. Eight cloud models run on your own API key at the provider’s price. Anything that speaks the OpenAI transcription API can be added by URL.

Before you download.

Is Flow really free?

Yes. Flow is MIT licensed and has no paid tier. Local models cost nothing to run. Cloud models are billed by the provider to your own API key, at their list price, with no markup from Flow.

What do I need to run it?

A PC with Windows 11. The default model runs on the processor, so you don’t need a graphics card. It is a 473 MB download on first run. An optional download lets Flow use an NVIDIA graphics card for the larger models.

Does it work offline?

Yes. With a local model, nothing touches the network. If you use a cloud model and the connection drops, Flow falls back to your local model and says so in the pill.

Which languages does it support?

English only in version 1. More languages are planned.

Is there a Mac version?

Not yet. Windows 11 comes first, and macOS follows the Windows 1.0 release.

Does the keyboard hook see what I type?

It compares each key event with your hotkeys and discards it. Nothing is stored or logged. The code is open, so you can check.

What does Flow send over the network?

Model downloads, the catalog refresh, update checks, and calls to providers you have set up. That is the whole list.

How is it different from Wispr Flow or Handy?

Wispr Flow is a polished subscription product that chooses the model for you. Handy is free and runs local models only. Flow is free like Handy and reuses Handy’s open-source speech engine, then adds cloud models on your own key, per-app profiles and a config file you can edit by hand.
